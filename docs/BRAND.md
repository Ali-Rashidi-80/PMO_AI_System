## Generation prompt (3D isometric)

Use this prompt when regenerating or adapting the logo for other sizes/formats:

> Premium 3D isometric app logo for **PMO AI System** — air-gapped local project-management AI automation. Central motif: a geometric **shield fused with a neural-network hub**, polished **teal (#147A8A)** and **mint (#3ECFB2)** gradients with subtle **copper (#C4956A)** edge highlights. Three floating translucent **document layers** with abstract Persian-inspired curved lines (no readable text). Soft studio rim lighting, glassmorphism, subtle depth of field, dark charcoal background **(#0B1A1F)**. Modern enterprise zero-trust aesthetic, crisp edges, **no typography**, square 1:1 composition, suitable for GitHub README and favicon at 128px.

### Negative prompt

> blurry, text, letters, watermark, cartoon, clipart, low poly noise, busy background, photorealistic human faces
